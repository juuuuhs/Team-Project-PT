担当：プロジェクトメンバー管理（招待・権限変更・削除）

チーム向けプロジェクト管理システム「WORKLOG」において、プロジェクト単位でメンバーを構成・管理する機能を、設計から実装まで担当しました。

メンバー検索・招待：未参加の会員のみをキーワードで検索し、招待できるように実装しました。招待時には、依頼者が当該プロジェクトのリーダー（OWNER）であるかをサーバー側で検証し、参加済みの会員への重複招待を防止しました。
招待の承認・拒否フロー：招待を PENDING 状態で保存し、招待された会員がマイページで承認するとプロジェクトメンバーとして登録、拒否すると REJECTED に更新される、状態ベースの設計としました。
メンバー権限の変更：リーダーがメンバーの役割を変更できるようにし、一般メンバーの画面には権限変更ボタンを表示しないよう、役割に応じて画面を制御しました。
メンバー削除：プロジェクトからメンバーを除外する機能を実装し、必須項目が不足したリクエストは 400 エラーとして処理しました。
構成：Controller → Command → DAO に役割を分けた MVC 構成（Java Servlet / JSP / Oracle）で実装し、機能ごとの処理を独立した Command クラスに分離しました。

一言まとめ：リーダーと一般メンバーの権限を区別し、招待から参加・権限変更・削除まで、メンバーのライフサイクル全体を管理する機能を実装しました。
